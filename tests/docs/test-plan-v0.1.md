# LingoQuest JP｜MVP 测试方案 v0.1

- 状态：实施基线
- 适用范围：英检 3 级、每日闯关、AI 二次试验模拟、家长报告与付费闭环
- 非本轮范围：协作社交、名著切片、学校／塾后台、准 2 级与 2 级内容
- 需求基线：[LingoQuest JP｜可开发 MVP PRD v0.1](https://bytedance.my.larkoffice.com/docx/DIJsdL2uwoc0EsxTohUmdO4Ky9f)

> 测试目标：验证 MVP 能在未成年人合规前提下，让学生持续完成英检 3 级学习，AI 模面在异常情况下安全降级，家长能理解学习价值并完成付费闭环。

## 1. 发布闸门

以下任一项未满足，禁止公开发布；隐私、未成年人、支付和 AI 评分问题不得以“灰度观察”替代修复。

| 领域 | 发布阻断条件 | 退出标准 |
|---|---|---|
| 隐私／未成年人 | 未完成家长绑定或独立语音同意时，仍能上传语音、购买、接收周报或保留长期学习记录 | 深链、刷新、回退、接口直调均无法绕过；审计记录可追踪 |
| AI 口语 | 低置信评分输出确定分数；断网或无麦克风无可用降级；语音处理地点、供应商、保存／删除策略未确认却开放公测 | 低置信统一降级；异常路径可恢复；法务阻断项全部关闭 |
| 学习主流程 | 注册后无法完成一个英检 3 级关卡；FSRS、生命值或错题反馈任一主链路不可用 | P0 学习用例全部通过，无 S0/S1 未关闭缺陷 |
| 家长／付费 | 学生端可直接购买；家长无法查看报告；支付成功后权益不到账；重复回调导致重复开通或扣费 | 身份与权益校验均由服务端执行；支付回调幂等 |
| 数据追踪 | WALD、模面完成率、家长绑定率、有效开口时长或订阅事件无法复算 | 测试环境事件完整，指标结果与定义一致 |
| 内容质量 | 生产题目缺来源、版权状态、级别、能力点或日本母语教研审核状态 | 缺任一字段的题目不能进入生产题库 |

## 2. P0 验收用例

### 2.1 账号、监护人与同意

| ID | 场景 | 前置条件 | 操作 | 预期结果 |
|---|---|---|---|---|
| P0-01 | 未成年人首次进入 | 新用户 | 选择英检 3 级并填写未成年出生年月 | 进入“等待家长绑定”；不要求真实姓名、学校或地区 |
| P0-02 | 未绑定权限限制 | 未成年、家长未绑定 | 尝试进入语音、付费、周报及长期进度 | 所有入口被拦截；最多仅允许一个无账号试玩关 |
| P0-03 | 绕过绑定限制 | 同 P0-02 | 通过深链、刷新、浏览器回退及接口直调访问受限功能 | 后端统一拒绝，不产生语音、购买、周报或长期进度数据 |
| P0-04 | 家长绑定成功 | 家长账号可用 | 通过独立链路完成绑定 | 学生与家长账号正确关联；产生 `parent_linked` 事件 |
| P0-05 | 独立语音同意 | 家长已绑定 | 查看并确认语音处理同意 | 单独展示目的、保存策略、处理地点与第三方信息；保存同意状态后才启用语音 |
| P0-06 | 拒绝语音处理 | 家长已绑定 | 家长拒绝语音处理后进入练习 | 进入固定题目的打字模式；网络请求中无语音负载 |
| P0-07 | 撤回同意 | 已同意语音处理 | 家长撤回同意，再进入模面 | 后续语音立即关闭；历史可识别语音进入删除流程；删除 SLA 作为发布前待决项跟踪 |

### 2.2 每日闯关与复习

| ID | 场景 | 前置条件 | 操作 | 预期结果 |
|---|---|---|---|---|
| P0-08 | 完成每日关卡 | 已绑定用户 | 完成一个 12–15 题关卡 | 目标时长 3–5 分钟可达；展示英检 3 级能力点、正确率和定着率变化 |
| P0-09 | 错题反馈 | 关卡中答错 | 查看反馈 | 解释具体规则及日语思考顺序与英语结构差异，不只显示对错 |
| P0-10 | 生命值扣减与恢复 | 生命值为 5 | 连续答错并等待恢复 | 每次错题扣 1；归零后按规则限制继续；30 分钟恢复 1，且不重复扣减 |
| P0-11 | FSRS 复习上限 | 新用户与老用户各一名 | 触发当日复习 | 新用户不超过 20 题，老用户不超过 60 题；复习题混入普通关卡 |
| P0-12 | 语顺块 | 存在语顺题 | 分别用触控和键盘完成排序 | 两种方式均可操作；唯一答案或经规则定义的等价答案可通过 |
| P0-13 | 冠词传感器 | 存在冠词题 | 分别触发超时和答错 | 超时不记为知识错误；答错解释指向具体冠词规则 |
| P0-14 | 和制英语猎人 | 存在已审核题目 | 作答并检查题目元数据 | 来源、版权状态、能力点和教研审核状态完整 |
| P0-15 | 母音切除低置信 | 录音含噪、过短或不可判定 | 提交发音 | 返回“无法评分，请重试”；不输出伪精确分数 |

### 2.3 AI 二次试验模拟

| ID | 场景 | 前置条件 | 操作 | 预期结果 |
|---|---|---|---|---|
| P0-16 | 完整模拟 | 已绑定且已同意语音 | 完成入室寒暄、音读、文章问答、图片问答、个人问题和结果报告 | 六阶段均完成；阶段事件完整且顺序正确 |
| P0-17 | 结果报告 | 已完成模拟 | 查看学生报告与家长摘要 | 包含得分区间、证据句、最多 3 条可执行建议及家长摘要 |
| P0-18 | 模面断网续传 | 模面进行中 | 完成两阶段后断网，再恢复网络 | 已完成阶段保留；从当前阶段继续；不重复提交、计分或计时 |
| P0-19 | 无麦克风权限 | 设备无麦或权限被拒绝 | 进入模面 | 明确提示原因；切换固定题目打字模式；结果标记“非完整模拟” |
| P0-20 | 运行中撤销麦克风 | 模面录音中 | 在系统设置中撤销权限 | 当前录音安全终止；不上传残缺语音；可重试或切换打字模式 |
| P0-21 | 低置信趋势排除 | 产生低置信结果 | 查看本次报告与历史趋势 | 显示“需再次录音”；本次不纳入趋势分或家长确定性结论 |

### 2.4 家长报告、付费与指标

| ID | 场景 | 前置条件 | 操作 | 预期结果 |
|---|---|---|---|---|
| P0-22 | 家长周报 | 已有一周学习数据 | 生成并从 LINE 查看周报 | 包含学习天数、定着率变化、模面结果、薄弱点及下周建议；不展示 XP、换装或角色等游戏指标 |
| P0-23 | 免费模面权益 | 免费用户且满足同意条件 | 完成一次完整模面后再次进入 | 首次完整体验可用；第二次触发家长付费入口 |
| P0-24 | 学生端购买拦截 | 学生账号 | 点击购买入口或直调购买接口 | 跳转或提示绑定家长处理；学生身份无法直接支付 |
| P0-25 | 订阅权益到账 | 家长账号 | 完成购买后返回学生端 | 重复模拟和历史报告开启；产生 `subscription_started` 事件 |
| P0-26 | 支付取消／失败 | 家长位于支付流程 | 取消或制造支付失败 | 不开通权益、不产生成功订单；可安全重试 |
| P0-27 | 支付重复回调 | 已完成一笔支付 | 重放成功回调 | 不重复扣费或重复开通；订单与权益状态保持一致 |
| P0-28 | 指标复算 | 测试环境已有行为数据 | 复算 WALD、模面完成率、绑定率和有效开口时长 | 与 PRD 口径一致；浏览、重复打开不计入 WALD |
| P0-29 | 非目标入口缺失 | MVP 构建包 | 检索协作社交、名著切片、学校／塾后台入口 | 不出现相关入口、埋点、空页面或灰色占位 |

## 3. 边界与降级场景

| 类别 | 必测边界 | 预期处理 |
|---|---|---|
| 隐私 | 同意前抓包、拒绝后重试、撤回后旧页面继续操作 | 无语音上传和第三方语音请求；服务端以最新同意状态为准 |
| 未成年人 | 深链、刷新、回退、多端登录、篡改年龄字段 | 受限能力由服务端身份与同意状态控制，不能依赖前端隐藏 |
| 断网 | 闯关提交中、模面阶段切换、报告生成中、支付回跳时断网 | 可恢复且幂等；不重复扣生命值、提交评分、计费或发放权益 |
| 无麦克风 | 权限拒绝、设备无麦、占用冲突、运行中撤权 | 明确告知并提供打字降级；报告标记“非完整模拟” |
| 低置信评分 | 静音、噪声、过短回答、识别失败、日语母语口音误判 | 不输出确定分数；要求重录；不进入趋势和家长确定性结论 |
| 法务／供应商 | 供应商、处理地点、保存期限、删除机制任一未定 | AI 语音公开测试保持阻断，仅允许内部桩或模拟数据测试 |
| 内容版权 | 缺来源、版权状态或教研审核字段 | 不能发布到生产题库；测试内容须有明确环境标识 |
| 付费 | 取消、失败、超时、重复回调、回调乱序、家庭成员异常 | 订单与权益幂等；失败不授权；最终状态可审计和人工校正 |
| 可访问性 | 键盘答题、读屏标签、焦点顺序、仅颜色传达状态 | 核心答题和报告查看可完成；状态不只依赖颜色 |
| 数据一致性 | 多端同时学习、重复提交、时区跨日、周报生成边界 | 学习记录不重复；每日／每周口径固定并可复算 |

## 4. 缺陷等级与跟踪

### 4.1 严重等级

| 等级 | 定义 | 示例 | 处置 |
|---|---|---|---|
| S0 阻断 | 造成合规、安全、资金或全局不可用风险 | 未同意上传语音、学生可购买、重复扣费、核心服务全不可用 | 立即停止发布；当日定责；修复后全量回归相关链路 |
| S1 高 | P0 主流程不可完成或结果具有明显误导性 | 低置信给确定结论、断网丢状态、P0 题型不可完成、关键埋点缺失 | 当前版本必须修复；绑定自动化或稳定回归用例 |
| S2 中 | 有替代路径但影响体验、理解或部分用户完成任务 | 周报字段缺失、反馈解释错误、无障碍问题影响部分用户 | 评估进当前迭代；明确 Owner 与修复版本 |
| S3 低 | 不影响任务完成的轻微展示问题 | 文案、对齐、非阻断样式问题 | 进入常规缺陷池，按影响排序 |

### 4.2 缺陷必填字段

- 模块、需求基线与用例 ID
- 用户角色、年龄状态、家长绑定状态、语音同意状态
- 环境、构建版本、设备／浏览器、网络条件
- 最小复现步骤、实际结果、期望结果、复现率
- 影响指标与严重等级
- 截图、录屏、脱敏日志或网络证据
- Owner、阻断状态、修复版本、回归结果及关联 PR／CI

### 4.3 关闭规则

1. S0／S1 必须绑定回归用例；无修复 PR、CI 或可复核回归证据不得关闭。
2. 隐私、未成年人、支付、AI 评分缺陷使用独立标签，不能只按功能模块归类。
3. 重新打开两次以上的缺陷应升级根因分析，检查相邻状态与同类入口。
4. 以下待决项作为发布风险独立跟踪：语音删除 SLA、AI 低置信阈值与离线评测门槛、供应商及处理地点、上线价格、触控目标与对比度、模面完成率目标。
5. 缺陷日报按“阻断发布／影响灰度／可延期”汇总，便于架构、设计、前端和业务／内容负责人处理。

## 5. 测试完成标准

- 所有 P0 用例执行完毕且通过；S0、S1 缺陷清零。
- 法务阻断项关闭；影响公开发布的待决项均有负责人、截止时间和明确退出条件。
- 核心事件可在测试环境查询，WALD、有效开口时长、家长绑定和订阅指标可复算。
- 日本母语教研完成上线题目抽检，题目来源台账可导出。
- 断网、无麦克风、拒绝／撤回同意、低置信评分均有可用降级路径并完成回归。
