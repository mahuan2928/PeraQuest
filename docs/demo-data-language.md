# Demo Data And Language Guide

Use these terms consistently when presenting the online demo.

## Standard Demo Outcome

- Guardian verification: `+20 XP`, `ガーディアンシールド`, unlocks learning.
- Level Check clear: `+100 XP`, `+50 コイン`, `レベルチェッククリア`, unlocks the review route.
- Review quest clear: `+15 XP`, `+5 コイン`, `復習の森クリア`.
- Listening cove trial: `+10 XP`, `+3 コイン`, `リスニング入り江体験`.
- Full guided demo total after all steps: `145 XP`, `58 コイン`, `4 / 5 スポット`.

## Product Terms

- Use `Quest Map` for the student adventure map.
- Use `冒険バッグ` for the student reward inventory.
- Use `スポット` for map progress points.
- Use `家庭サポートメモ` for guardian-friendly next action and encouragement.
- Use `デモ用の回答` for the stable level check answer path.

## Talk Track

- Student story: learning outcomes become adventure progress.
- Guardian story: parents see what happened today, what comes next, and how to encourage the child.
- Safety story: guardian verification gates the formal learning flow.
- Stability story: the demo answer path keeps the level check result explainable.

## Avoid

- Do not describe payment as ready.
- Do not expose tokens, API paths, raw JSON, HTTP status, or debug wording.
- Do not call local-only review/listening rewards persisted backend rewards.
